# 3LINK Networks - Responsive Web & Mobile App Prototype

A high-fidelity interactive web prototype built for **3LINK Networks**, optimized for widescreen desktop web apps and pixel-perfect mobile-first viewports. This portal is built using **HTML5**, **CSS3**, and **Tailwind CSS (via CDN)**.

## 🚀 Portals & Roles
The prototype is divided into 4 key user interfaces:
1. **Customer App**: Manage active packages, view data usage statistics, perform live speed tests, recharge balance dynamically, browse equipment in the store, and open support tickets.
2. **Reseller Portal**: Manage user databases, register new customers, monitor collections, and view earnings statistics.
3. **Technician/Employee Portal**: Duty check-in/attendance registry, task queues, routing maps with coordinates, and detailed ticket management.
4. **Admin Dashboard**: Comprehensive overview of metrics, revenue charts, payment gateways distribution, and recent transaction ledgers.

## 🛠️ Responsive Grid Architecture
All pages detect the device viewport dynamically:
- **Mobile (Default)**: Fits perfectly into a 375px native app layout with sticky bottom navigation tabs and quick action modules.
- **Desktop (16:9 Widescreen)**: Automatically transforms into a full-width desktop portal with a matching top header navigation bar, sidebar panels, and responsive multi-column layouts.

## 🔗 How to run
Simply open `index.html` in any modern web browser. A floating **Demo Navigator Widget** (`demo-nav.js`) is loaded at the bottom-right corner of all screens to easily jump between all 20 pages during review.
